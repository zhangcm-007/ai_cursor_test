# 边界值规则（boundary）

> 此文件供 testcase-generator skill 在 Step 3 覆盖维度检查时使用，
> 确保边界场景不遗漏。

---

## 字符串字段

| 场景 | 说明 |
|------|------|
| 空字符串 | `""` 或不传该字段 |
| 仅空格 | `"   "` |
| 最小长度 | 字段定义的最小字符数（如最少1位） |
| 最大长度 | 字段定义的最大字符数（如最多255位） |
| 超出最大长度 | 最大长度 + 1 个字符 |
| 特殊字符 | `<>'"&;` SQL 注入、XSS 注入字符 |
| 超长字符串 | 10000字符以上，测试截断与性能 |

## 数值字段

| 场景 | 说明 |
|------|------|
| 0 | 零值是否被允许 |
| 负数 | 负整数、负小数 |
| 最小值 | 业务定义的最小值（如年龄≥0） |
| 最大值 | 业务定义的最大值 |
| 最大值+1 | 超出上限 |
| 小数精度 | 超出允许精度（如金额只允许2位小数，传3位） |

## 日期/时间字段

| 场景 | 说明 |
|------|------|
| 过去时间 | 早于当前时间 |
| 未来时间 | 晚于当前时间 |
| 当前时刻 | 边界临界点 |
| 无效格式 | `2999-99-99`、`not-a-date` |
| 时区边界 | 夏令时、跨时区场景 |

## 列表/集合字段

| 场景 | 说明 |
|------|------|
| 空列表 | `[]` |
| 单个元素 | 最小有效列表 |
| 最大数量 | 业务允许的最多元素数 |
| 超出最大数量 | 最大数量+1 |
| 重复元素 | 列表中含重复值 |
