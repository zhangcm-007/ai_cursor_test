## 详细测试点

### 一、功能测试点

#### 1.1 数据筛选（需求第 1 条）

| 测试点ID | 测试点描述 | 说明/边界 |
|----------|------------|-----------|
| TP-01 | 仅保留 ticker 与用户输入一致的新闻；从 ticker_sentiment 列 JSON 中取 relevance_score、ticker_sentiment_score | 正常 |
| TP-01 | relevance_score > 0.5 的保留，≤ 0.5 的排除，筛选后条数及内容正确 | 正常 |
| TP-01 | 多条新闻中混合匹配/不匹配 ticker、混合 relevance 大于/小于 0.5，验证最终参与计算的数据集正确 | 正常 |
| TP-07 | relevance_score 恰好等于 0.5 时，按需求“>0.5”应排除 | 边界 |
| TP-07 | 用户输入 ticker 在所有新闻中无匹配时，应有明确处理（如无数据提示或结果为 0/空） | 边界 |

#### 1.2 单条情绪值截断（需求第 2 条）

| 测试点ID | 测试点描述 | 说明/边界 |
|----------|------------|-----------|
| TP-02 | 公式 max(min(ticker_sentiment_score, 1.0), -1.0)：情绪值在 [-1, 1] 内不改变 | 正常 |
| TP-02 | 情绪值 > 1（如 1.5）截断为 1.0 | 边界 |
| TP-02 | 情绪值 < -1（如 -1.2）截断为 -1.0 | 边界 |
| TP-08 | 情绪值恰好为 1.0、-1.0、0 时，截断后保持不变 | 边界 |

#### 1.3 每日情绪值加权（需求第 3 条）

| 测试点ID | 测试点描述 | 说明/边界 |
|----------|------------|-----------|
| TP-03 | S_daily = Σ(Relevance × Sentiment) / Σ(Relevance)，使用截断后的情绪值与筛选后的 relevance，计算与预期一致 | 正常 |
| TP-03 | 单日仅一条新闻时，S_daily 等于该条截断后情绪值 | 边界 |
| TP-03 | 单日多条新闻，手工计算 S_daily 与程序结果一致 | 正常 |
| TP-08 | Σ(Relevance) 为 0 时的防护（如理论上 relevance 全为 0），避免除零或明确业务处理 | 异常/边界 |

#### 1.4 整体区间情绪值（需求第 4 条）

| 测试点ID | 测试点描述 | 说明/边界 |
|----------|------------|-----------|
| TP-04 | 根据每日情绪值及权重衰减公式计算整体区间情绪值，时间越近权重越高、越远越低 | 正常 |
| TP-04 | 仅单日有数据时，整体情绪与当日 S_daily 一致（或按约定规则） | 边界 |
| TP-04 | 多日数据时，权重衰减系数与需求公式一致，结果可复算 | 功能 |
| TP-09 | 单日情绪分析输出与 S_daily 一致；整体情绪分析输出与整体区间情绪值一致 | 功能 |

### 二、输入与数据源测试点

#### 2.1 用户输入

| 测试点ID | 测试点描述 |
|----------|------------|
| TP-05 | 用户 ticker 为空、null、空格时的处理与提示 |
| TP-05 | ticker 大小写：与 JSON 中 ticker 比较是否大小写敏感（如 AMZN vs amzn） |
| TP-05 | ticker 含非法字符、超长字符串时的校验与提示 |

#### 2.2 ticker_sentiment 列与 JSON

| 测试点ID | 测试点描述 |
|----------|------------|
| TP-06 | ticker_sentiment 为合法 JSON，且含 ticker、relevance_score、ticker_sentiment_score 时解析正确 |
| TP-06 | 缺少 relevance_score 或 ticker_sentiment_score 或 ticker 时的处理（跳过该条/默认值/报错） |
| TP-06 | relevance_score、ticker_sentiment_score 为字符串数字（如 "1.000000"）时能正确转为数值参与计算 |
| TP-06 | ticker_sentiment 非 JSON、格式错误、空字符串时的处理与错误提示 |

### 三、边界与异常小结

| 测试点ID | 测试点描述 |
|----------|------------|
| TP-07 | 无匹配 ticker、relevance_score 全 ≤ 0.5、单日无新闻 |
| TP-08 | 情绪值 ±1、0；relevance 为 0；Σ(Relevance)=0 |
| TP-05/TP-06 | 输入与数据源异常均应有明确反馈，不导致未捕获异常或错误结果 |

### 四、非功能（可选）

| 测试点ID | 测试点描述 |
|----------|------------|
| TP-10 | 大量新闻条数时的性能与内存占用可接受 |
| TP-11 | 日期区间较大、多日数据时，权重衰减计算效率与结果正确性 |
